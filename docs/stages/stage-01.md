## 6. Foundation Decisions

### Next.js

Use:

- App Router;
- `src/` directory;
- Turbopack;
- TypeScript;
- ESLint;
- Tailwind CSS.

### TypeScript

Strict mode is enabled:

`"strict": true`

Type checking uses:

`next typegen && tsc --noEmit`

Reason:

Next.js route-aware global types such as `LayoutProps` are generated by Next.js type generation and must exist before standalone TypeScript validation.

### Import alias

Use:

`@/* -> ./src/*`

### React Compiler

Not enabled during Stage 1.

Reason:

No demonstrated Stage 1 need exists for an additional compilation layer.

### TanStack Query

Not installed.

Reason:

No Stage 1 client-side server-state use case exists.

### Supabase

Not installed during the initial web foundation.

Reason:

Production Supabase integration and business data architecture belong to Stage 2.

### Zod

Not installed during initial foundation.

Reason:

No Stage 1 runtime validation use case currently requires it.

### shadcn/ui

Not initialized during Stage 1.

Reason:

Stage 1 contains no reusable product UI or design-system requirement that justifies initializing a component library.

shadcn/ui remains part of the planned technology direction and may be introduced during the appropriate Product Design / product implementation Stage when there is a concrete component requirement.

### Test Runner

Vitest is included in Stage 1.

Installed testing foundation:

- Vitest;
- React Testing Library;
- jsdom;
- `@vitejs/plugin-react`.

The test foundation verifies React rendering and TypeScript path aliases without introducing business tests before business logic exists.

### Playwright

Not installed during Stage 1.

Reason:

There is no meaningful end-to-end user journey yet.

Playwright remains planned for later critical E2E coverage when real public or internal workflows exist.

### GitHub Actions

Included during Stage 1.

CI runs for pushes and pull requests targeting `main`.

The CI quality job performs:

1. `npm ci`;
2. `npm run lint`;
3. `npm run typecheck`;
4. `npm test`;
5. `npm run build`.

No deployment is performed by Stage 1 CI.

!.env.example
